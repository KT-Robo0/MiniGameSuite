# 初期要望

`/kickoff` を始める前に先生から聞いている前提。ヒアリングではここに書かれたことを聞き直さず、確認だけする。

## 作るもの

- **ミニゲーム集**（ブラウザで遊べるものを想定）

## 作る人・使う人

- 作る人：プログラミング教室の**中学生**。**チームで作る**（1人1ゲームの分担を想定）
- 使う人：作ったゲームは**インターネット上に公開**し、誰でも遊べるようにする

## 構成の希望

- 同じ教室の TypingSuite と**似た構成**にしたい（`reference-typingsuite/` 参照）
  - TypeScript + Vite（+ React）で、`core/`（土台）と `games/`（1人1ディレクトリ）を分ける
  - 新しいゲームは registry への登録で増やし、土台を書き換えない
  - main への push で自動公開。作業ブランチの push でプレビュー URL が出て、本人が確認できる
  - 生徒向けの手順書（TypingSuite の `src/tasks/README.md` 相当）を用意する

## まだ決まっていないこと（ヒアリングで決める）

- ゲームの中身・最初に作る本数
- 記録・ランキングなどのデータ保存が要るか（要らなければ Supabase・認証は不要になる）
- スマホでも遊べるようにするか
- 公開先（TypingSuite と同じ Cloudflare か）と、レビュー・マージの担当者
