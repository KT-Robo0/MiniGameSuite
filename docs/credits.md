# Credits

他の人が作った素材（画像・音・フォント・コード）の出典とライセンス。**承認不要で追記してよい。**

ゲームはインターネットに公開するため、使ってよい素材かどうかを先に確認し、使ったらここに書く。
**出典がわからない素材は使わない。** 使わなくなっても行は消さず「使わなくなった日」を埋める。
