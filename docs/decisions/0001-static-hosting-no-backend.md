# 0001. サーバーなしの静的サイトにし、TypingSuite と同じ Cloudflare Workers で公開する

- **日付**: 2026-10-18
- **ステータス**: 承認

## 背景

ミニゲーム集を中学生チームで作り、インターネットに公開する。
最初のゲームはボタンを押すだけの簡単なもので、記録の保存やログインは要らない。
教室には TypingSuite で使っている Cloudflare アカウントがある。

## 決定

1. 記録の保存・ログインはしない。バックエンド（Supabase など）は使わない
2. TypingSuite と同じ構成（TypeScript + React + Vite）で作る
3. TypingSuite と同じ Cloudflare アカウントの Workers（Static Assets）で公開し、
   Workers Builds で GitHub と連携して push で自動公開する

## 理由

- 保存しないなら、ビルドした静的ファイルを配るだけで足りる。管理するものが最小になる
- TypingSuite と同じ構成にすると、教室で学んだことと手順を使い回せる
- push で自動公開・プレビュー URL が出るため、作った本人がすぐに確認・共有できる

## 却下した選択肢

| 選択肢 | 却下理由 |
|--------|----------|
| Supabase で記録を保存 | 今は不要。ランキングは利用者入力の公開になるため、先生と相談してから |
| Vanilla JS | ゲームが増えたときの登録の仕組みが作りにくく、TypingSuite と書き方がずれる |
| CoreServer で静的配信 | FTP の手動アップロードになり、複数人だと事故が起きやすい |

## 影響

- ランキングなどの保存機能を足すときは、新しい ADR でバックエンドを決め直す
- ホスティングの移行は、`dist/` を別の場所に置くだけなので軽い
